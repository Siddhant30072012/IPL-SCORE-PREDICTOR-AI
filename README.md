# IPL-SCORE-PREDICTOR-AI
# 🏏 IPL Data-Driven Score & Chasing Predictor App
This is a machine learning app I built at 14 years old to track cricket run-chase logic and calculate live second-innings win probability.

## 🛠️ Features Developed
*   **Data Cleaner Pipeline:** Filters massive historical ball-by-ball IPL datasets into neat match statistical data matrices using Pandas.
*   **Algorithmic Engine:** Implements advanced required run rate and wicket loss calculations.
*   **Gradio Web App Interface:** Generates user-friendly dropdown forms and sliding controls.
